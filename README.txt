MARKET BASKET ANALYSIS USING APRIORI

1. Extract the ZIP file.
2. Open a terminal/Command Prompt inside the extracted folder.
3. Run: jupyter notebook
4. Open Market_Basket_Analysis_Apriori.ipynb
5. Run the notebook cells in order using Shift+Enter.
6. First cell installs dependencies. Internet may be needed for package installation.
7. The CSV is synthetic practice data with 500 transactions.
8. The notebook saves two charts and two results CSV files.
